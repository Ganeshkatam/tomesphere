# Workspace Execution Rule: Task-Driven Workflow

## Principle
Before starting any new implementation, feature, bug fix, or refactor:
1. Ensure the user-facing `task.md` artifact is active and up to date.
2. Outline all work items, subtasks, verification steps, and acceptance criteria in the task tracker.
3. Check off tasks as each step is completed and verified.
4. Keep the task tracker current with the latest progress.
