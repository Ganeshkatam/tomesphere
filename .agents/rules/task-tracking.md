# Workspace Execution Rule: Task-Driven Workflow

## Principle
Before starting any new implementation, feature, bug fix, or refactor:
1. Ensure `task.md` exists in the repository root.
2. Outline all work items, subtasks, verification steps, and acceptance criteria in `task.md`.
3. Check off tasks as each step is completed and verified.
4. Keep `task.md` up to date with the latest progress.
