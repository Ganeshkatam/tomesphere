# TomeSphere Product Design

This directory contains the complete visual and structural specifications for TomeSphere. These documents are the **source of truth** for all frontend implementation decisions.

## Design Phase Index

Before writing any UI code, consult these documents in order:

1. **[Product Vision](./design_board_0_product_vision.md)**
   Defines *what* TomeSphere is (identity, personas, core goals).
2. **[Information Architecture](./design_board_1_ia.md)**
   Defines *where* users go (object hierarchy, content hierarchy, navigation).
3. **[Layout Architecture](./design_board_2a_layouts.md)**
   Defines the macro structural shells and their responsibilities.
4. **[Experience Principles](./design_board_2b_experience.md)**
   Defines *how* TomeSphere feels to use (interaction philosophy).
5. **[Structural Wireframes](./design_board_3a_wireframes.md)**
   Defines the low-fidelity layout of core pages (no colors, no spacing, just structure).
6. **[Spacing & Grid](./design_board_3b_spacing.md)**
   Defines the responsive grid, spacing tokens, margins, and containers.
7. **[Visual Design System](./design_system.md)**
   Defines typography, colors, elevation, states, and accessibility rules.
8. **[Design Governance](./DESIGN_GOVERNANCE.md)**
   Defines the strict rules required to prevent visual and architectural drift in the UI.

> **Note**: High-fidelity mockups generated during this process are considered **validation** of these systems, not the specification itself. The Markdown documents in this directory remain the absolute source of truth.
